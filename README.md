One funny single-line sport the Olympics rejected — a made-up event, real enough
to sound like a broadcast, absurd enough to be funny, short enough to fit in
200 characters.

## The entry

> Men's 100-metre IKEA assembly: Sweden's Lars builds the bookshelf in 38 seconds, then loses gold for the one screw left over.

Picked by duelling five candidate lines on funniest, best gate fit, and freshest
angle: the winner ends on new information (the one screw left over) and carries
concrete specifics (Sweden, Lars, 38 seconds).

## Run

```sh
node main.ts
```

Writes the single line to `/output/entry.txt`.
